# Cervus-Linux
An Ubuntu-based distribution. This was created purely as an experiment, so don't judge it too harshly. 

Cervus Linux is an experimental Linux distribution based on Ubuntu.

*Project status: Pre-Alpha / In active development.*

# 📖 About

Cervus Linux is an educational and research project. Our goal is to understand how modern Linux distributions work from the inside and build our own system on top of a stable and popular foundation — Ubuntu.

The project is at its earliest stage. Right now, we are just laying the groundwork and planning the architecture.
# 🎯 Why?

The main reason for creating Cervus Linux is learning and genuine curiosity.

We want to practically explore the process of building a distribution, configuring the environment, creating an installer, and branding. This is our way to dive into the Open Source ecosystem and gain experience you can't get just by reading documentation.

# ⚠️ Disclaimer

Please don't judge us too harshly!
This is our first experience in creating a distribution. Right now, there might be no code, ready-made ISO images, or instructions here. The project will evolve gradually, through trial and error. We will be very glad for any support, advice, and constructive criticism from the community!
